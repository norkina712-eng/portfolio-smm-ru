# Портфолио SMM-специалиста — Норкина Валерия

Сайт-портфолио на React. Русская версия [английского портфолио](https://norkina712-eng.github.io/portfolio-smm/), тот же шаблон, те же кейсы и примеры публикаций.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

1. Пуш в `main` → GitHub Actions собирает `dist/`
2. Готовый сайт публикуется в ветку `gh-pages`
3. В репозитории → **Settings → Pages** → Branch: **gh-pages** → `/ (root)`

Базовый путь на GitHub Pages: `/portfolio-smm-ru/`
